» What's new

  • SmartFoxServer 2X 2.19 comes as a standalone installer. As such it must be installed in a new directory and cannot be used as an update for a previous installation.

    Server:
    • NEW: Tomcat is updated to version 9.0.70
    • NEW: GeoLite database updated
    • NEW: Extension Flood Filter, allows to configure Extension calls rate limits on a per-request basis. (See docs here)
    • FIX: issue with GameAPI where sending an invitation from the server side would raise an exception

    Admin Tool:
    • NEW: in login view, port and encryption checkbox set automatically based on the URL protocol.
    • FIX: menu button on mobile devices partially not working due to notifications container covering it.
    • FIX: in Dashboard module, server uptime slowly diverges if browser window is minimized or loses focus.
